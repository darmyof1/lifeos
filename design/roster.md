# Sovereign Life OS — Agent Roster

## Executive & Technical Chiefs

| Department           | Chief Title                        | Abbrev | Function                                                                                   |
|----------------------|------------------------------------|--------|--------------------------------------------------------------------------------------------|
| Operations           | Chief Operating Officer            | COO    | Primary user interface. Routes all daily requests, coordinates dept chiefs, produces status reports, owns the event bus. |
| Strategy             | Chief Strategy Officer             | CSTO   | Holds the system constitution (SOUL.md, IDENTITY.md). Audits all agents quarterly. Defines SOPs for every other chief. Provides strategic vision reviews. |
| Information Tech     | Chief Information Officer          | CIO    | Manages Ubuntu VM, Docker containers, Ollama models, AWS infrastructure, IoT devices (glasses, watch), and API cost lifecycle. |
| Information Security | Chief Information Security Officer | CISO   | Enforces data diode rules, audits all external API calls, manages KMS keys, reviews dark archive integrity, approves new skills before installation. Escalates critical events directly to CEO. |
| Knowledge            | Chief Knowledge Officer            | CKO    | Owns the three-tier memory architecture. Runs the nightly Janitor, promotes logs from L1→L2→L3, maintains the dark archive pipeline, audits memory quality. |
| Metrics              | Chief Metric Officer               | CMO    | Monitors cross-domain data patterns. Produces the weekly life dashboard. Surfaces correlations no individual dept chief can see (e.g. sleep deficit → gym performance drop). |
| Staff                | Chief of Staff                     | COS    | Resolves inter-department conflicts before they reach the COO. Filters and aggregates dept chief reports. Manages scheduling conflicts between competing domain priorities. |
